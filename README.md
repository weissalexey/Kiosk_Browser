# \# KioskBrowser Android

# \### Enterprise Optimized WebView for Android 10

# 

# High-performance, production-ready WebView browser built specifically for

# industrial and logistics environments.

# 

# Designed for:

# \- Zebra devices

# \- Rugged enterprise terminals

# \- Android 10 hardware

# \- Low RAM systems (2GB)

# \- Continuous 24/7 operation

# 

# ---

# 

# \## Philosophy

# 

# This is not a general purpose browser.

# 

# KioskBrowser is a \*\*single-purpose, high-stability WebView container\*\*

# engineered for internal web systems such as ScanApp (ASP.NET MVC).

# 

# Every feature is intentionally minimized to maximize:

# 

# \- Stability

# \- Predictability

# \- Memory efficiency

# \- CPU efficiency

# \- Instant user feedback

# \- Long-term uptime

# 

# ---

# 

# \## Core Capabilities

# 

# \### ⚡ Performance Optimized WebView

# 

# \- Hardware accelerated rendering

# \- Render priority tuned

# \- Minimal WebView configuration

# \- No unnecessary caching

# \- No background services

# \- No tabs

# \- No file handling

# \- No multimedia

# \- No external navigation

# \- Reduced GC pressure

# \- Optimized lifecycle management

# 

# ---

# 

# \### 🏭 Enterprise Stability

# 

# \- Android 10 safe configuration

# \- Render process crash recovery

# \- Automatic reload watchdog

# \- Network error detection

# \- HTTP error detection

# \- Console error detection

# \- Optional audible alert on errors

# \- Back button protection

# \- Controlled external intent handling

# 

# ---

# 

# \### 📦 ScanApp / ASP.NET MVC Optimized

# 

# \- Auto focus first input field

# \- Full text selection on focus (overwrite mode)

# \- Fast hardware keyboard input

# \- Optimized for AJAX DOM refresh

# \- Minimal JavaScript injection

# \- IME (soft keyboard) toggle

# \- No layout breaking zoom

# 

# ---

# 

# \### 🎛 Overlay Control Bar

# 

# Optional configurable overlay bar:

# 

# \- Position: Top / Bottom

# \- Overlay mode (does not resize WebView)

# \- Custom JPG branding support

# \- Integrated control buttons

# \- Can be completely disabled

# 

# ---

# 

# \### 🔍 Zoom Slider

# 

# \- Range: 50% – 150%

# \- Instant apply (no page reload)

# \- Layout safe (`textZoom`)

# \- Persistent via SharedPreferences

# \- Optimized for industrial UI scaling

# 

# ---

# 

# \### 🔒 Immersive Kiosk Mode

# 

# \- Fullscreen

# \- Hidden navigation bar

# \- Hidden status bar

# \- Orientation lock

# \- Designed for dedicated device environments

# 

# ---

# 

# \## Technical Specifications

# 

# | Parameter | Value |

# |-----------|--------|

# | Package | `com.example.kioskbrowser` |

# | minSdk | 24 |

# | targetSdk | 29 |

# | Android Target | Android 10 |

# | Build | R8 + resource shrink enabled |

# | Hardware Acceleration | Enabled |

# | Optimized For | 2GB RAM devices |

# 

# ---

# 

# \## What Is Intentionally Not Supported

# 

# \- Multiple tabs

# \- File downloads

# \- File uploads

# \- Media playback

# \- Video

# \- Third-party browsing

# \- Complex browser APIs

# 

# This is deliberate to maintain performance and stability.
